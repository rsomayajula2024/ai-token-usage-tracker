Tokenomics — Privacy Policy ✅ No data collected Last updated: August 2026 Overview Tokenomics is a browser extension that tracks and optimizes token usage on Claude.ai and ChatGPT. We are committed to your privacy. Tokenomics does not collect, transmit, or store any personal data on external servers of any kind. Data Storage All data generated by Tokenomics is stored exclusively on your local device using the browser's built-in chrome.storage.local API. This includes: Daily token usage statistics Token savings logs User-created context snippets Widget position and display preferences This data never leaves your device and is never transmitted to any server, including ours. Permissions Used storage — saves token stats and snippets locally on your device only tabs — used solely to show the on-page widget when requested from the popup clipboardRead — used only when you explicitly click "Paste from clipboard" clipboardWrite — used only when you click "Save & Switch" to copy a conversation summary host permissions (claude.ai, chatgpt.com) — required to read message text from the page to estimate token counts and insert compressed messages into the chat composer No Analytics or Tracking Tokenomics contains no analytics, no telemetry, no crash reporting, and no third-party tracking of any kind. We do not know who uses Tokenomics or how they use it. No Data Sharing We do not sell, share, or transfer any user data to third parties for any purpose. No Remote Code Tokenomics does not load or execute any remote code. All extension code is bundled locally within the extension package. Contact For privacy questions or concerns, please open an issue on our GitHub repository.
